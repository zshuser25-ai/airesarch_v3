# 第一阶段：预准备

在项目根目录运行 `python3 workflow.py start`。依次填写科研目标与对比基线、测试使用模型、数据集地址、可用硬件，每项多行输入，以单独一行 `.` 结束。

全部填写后分配新的 `try001/`、`try002/`……，把输入保存为 `preparation.md`。本阶段只记录研究定义。

数据提供原始入口及任务说明即可，第二阶段开始时解析入口并固定总量的开发 5%、正式 30%、补测剩余 65%，不要求用户先提供三套数据。

随后执行 `python3 workflow.py run --try try001`；每个 AI 步骤都读取准备材料，按本次输入决定模型、基线、指标、预算和硬件。
